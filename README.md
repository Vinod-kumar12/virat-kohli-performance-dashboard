Virat Kohli Performance Analysis Dashboard 🏏📈
A comprehensive data visualization project analyzing the career trajectory, format-wise dominance, and match-impact of Virat Kohli. This dashboard provides a 360-degree view of "The King’s" journey from his debut to the current 2026 season.

🚀 Project Overview
The goal of this project was to clean, process, and visualize nearly two decades of international and domestic cricket data to identify patterns in scoring, consistency across different playing conditions, and the correlation between individual performance and team wins.

📊 Key Insights Featured:
-> Total Run Accumulation: Tracking the milestone of 28,000+ international runs.

-> Format Distribution: A Donut Chart breakdown showing dominance in ODIs (52.44% of total runs).

-> Geographical Dominance: A Treemap analysis of runs scored against major oppositions (Australia, England, New Zealand) and host countries.

-> Performance Trends: A "Total Runs by Year" area chart highlighting the significant "Second Peak" in 2024-2025.

-> Clutch Factor: A bar chart comparing innings played in "Won" vs. "Lost" matches, showcasing a 58.17% career win rate.

📈 How to Use
-> Clone the repository.

-> Open the .pbix or .twb file.

-> Use the "Format" Slicer (top right) to filter data between ODI, Test, and T20I to see how the KPIs shift across formats.
